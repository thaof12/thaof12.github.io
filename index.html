Mở dự án
Vai trò: Game Designer & Developer
Công nghệ:
Cocos Creator 3.8 TypeScript Physics 2D WebGL / HTML5 Vercel Git
  • Thiết kế màn giải đố: Xoay quanh 3 hiện tượng vật lý: lực đàn hồi lò xo (định luật Hooke), khúc xạ/phản xạ tia sáng qua cụm thấu kính, cơ học cáp kéo – ròng rọc thang máy.

Eureka - Website hỗ trợ học tập môn vật lý

Mở dự án
Vai trò: Developer & System Designer
Công nghệ:
ReactJS Vite Express.js Supabase (PostgreSQL) Authentication (JWT) Cocos Creator Vercel
  • Hệ thống phân quyền 4 vai trò: Guest, Student (bài giảng, máy tính vật lý, game, PK 1vs1), Teacher (tạo lớp, giao bài), Admin (quản lý người dùng, nội dung, duyệt giáo viên).
  • Hệ sinh thái học tập: Cung cấp bài giảng tương tác, phòng thí nghiệm ảo chạy trên HTML5 Canvas, công cụ máy tính vật lý và tích hợp trực tiếp game 2D Robot Eureka qua iframe.
  • Hệ thống & tối ưu: Thiết kế kiến trúc 3 tầng (React, Express, PostgreSQL), thiết lập bảo mật Row Level Security và tối ưu hóa hiệu năng tải trang đa thiết bị.
